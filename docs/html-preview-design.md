# HTML 版本与预览设计

日期：2026-11-05。基线：工作区源码声明版本 0.4.4。
状态：设计已确认并完成本地实施。用户于 2026-11-05 确认完整方案，随后授权继续实施。已生成开发安装包并在隔离测试仓库验证；未安装到日常使用仓库，未提交或发布。

## 已确认范围

1. 文章专属目录中的 HTML 列为文章版本；混有多篇文章的目录优先同名关联，无法确定的 HTML 独立显示，不重复挂到多篇文章下。具体规则见下文。
2. 首版支持 HTML/CSS、图片和本地配套资源，默认不运行网页脚本。
3. 首版完成版本列表与 HTML 原样预览。Markdown 继续承担现有批注流程；HTML 的划线、图片笔记、音频和 PDF 导出不在首版扩展范围。
4. 有 Markdown 时保持现有默认版本优先级；只有 HTML 时允许直接打开 HTML。

“原样预览”指保留静态内容及原有样式，不承诺脚本驱动内容的完整效果。

## 已核实的改动入口

- `plugin/reading-core.js`：统一 html、htm 的来源类型。
- `plugin/main.js`：`isLibraryCandidate` 接纳 HTML；`splitArticleDirectoryGroup` 增加关联规则。
- `articleVersionLabel`、`articleVersionRank`、`buildArticleLibraryGroups`、`openBestVersion`：补齐标签及默认打开策略，避免 HTML 被标为 Markdown 或抢占 Markdown 优先级。
- 版本列表复用 `selected.versions` 的真实文件名及卡片结构。
- `openLibraryVersion`：增加内部 HTML 预览路由。当前 Reader 固定使用 MarkdownRenderer，标注逻辑不能直接跨用到隔离 HTML 文档。
- 当前 manifest 并非仅桌面端；首版在 Mac Obsidian 实际验收，尽量使用跨平台接口，不承诺未经验证的移动端可用性。

## 已确认的归组规则（Q7）

- 同目录、同名的 HTML 与 Markdown 优先关联。
- HTML 所在目录的 Markdown 已全部属于同一文章组时，不同名 HTML 可加入该组。
- 同目录有多个文章组时，无法同名关联的 HTML 独立显示。
- 只有多个 HTML 的目录，每个 HTML 独立成篇。
- 不因上层目录只有一篇 Markdown 就自动吸收子目录 HTML。
- 保持既有 Markdown/PDF 分组结果和组标识稳定，HTML 在其基础上关联；匹配存在歧义时独立显示。

## 已确认的预览与资源规则（Q5、Q6、Q8）

- 版本区新增 HTML 类型、真实文件名和“预览”按钮。
- 在 Obsidian 内打开独立预览标签页；重复打开同一文件切回已有标签。
- 顶部固定文件名和刷新按钮，内容区独立滚动，不显示 Markdown 批注侧栏。
- 保留 HTML 自身颜色和排版，不随 Obsidian 深色主题强制转换。
- 支持仓库内相对路径的图片、CSS、字体，包括 `../assets/`；不读取仓库外文件。
- 不自动加载网络图片、CSS、字体，不运行网页脚本。
- 页内锚点在预览内跳转；普通网页链接仅在用户点击时交给系统浏览器；仓库内 HTML 链接继续交给插件预览。
- 缺失或被阻止的资源不阻断可用正文，显示简短的不完整展示提示。
- 首版实际验收平台为 Mac 桌面端 Obsidian。

## 技术实施建议

1. 将 `.html`、`.htm` 统一为 HTML 类型；先完成现有文章组，再按直接父目录与文件名关联 HTML，避免改变已有文章组身份。
2. 增加独立的 HTML 预览视图与打开路由；用隔离文档承载完整页面，不将完整 HTML 注入 Obsidian 主界面。保存源文件路径以支持标签恢复，手动刷新重新读取文件和资源。
3. 将资源解析放入独立模块：按 HTML 或各 CSS 文件自身目录解析引用，覆盖 CSS 内的 url()/导入及嵌套相对路径，规范化后检查仓库边界。拒绝文件路径越界及可执行 URL；所有自动远程请求必须受限制，包括 CSS 的间接引用。
4. 禁用脚本、事件处理器和自动导航，阻止嵌入远程页面；使用隔离与内容策略形成约束。链接处理需与禁用页面脚本兼容，不以开放页面脚本来实现导航。
5. 不复用面向打印的 HTML 清理器以免破坏原始排版；具体资源 URL 机制与隔离配置先通过 Mac Obsidian 小型原型验证，再接入版本列表。
6. HTML-only 条目的标题先沿用现有文件名/目录名回退规则；不新增全文搜索、自动摘要或阅读记录生成。多个可选 HTML 用稳定文件路径顺序选取默认项，不按内容推断优劣。
