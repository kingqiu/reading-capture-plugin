# HTML 阅读空间与标注扩展

状态：设计已确认；用户已确认 Q1–Q8 及汇总后的完整方案，作为后续实施与验收依据。已完成代码实现和 Mac Obsidian 隔离仓库验证。日期：2026-11-05。
基线：日常仓库已安装的 0.4.6 + HTML 预览增量；不能直接以工作区 0.4.4 构建覆盖日常插件。

## 用户目标

减少或收起 HTML 阅读顶部的非正文空间；评估在 HTML 内边阅读边标注，并复用既有集中存放阅读记录的方式。

## 已核实事实

- 当前 SPAR 预览顶部包括 Obsidian 视图标题栏、插件文件名/刷新栏、常驻状态提示。
- 当前窗口实测 CSS 高度分别约 38.3、55、36.9 px，合计约 130 px；截图为高像素密度，不应将截图像素当作 CSS 高度。
- 标签页已经显示文件名；文件名工具栏重复显示同一信息。
- 静态预览禁用页面脚本，插件可访问 iframe 文档，现有链接跳转已经使用这条路径。
- 当前预览窗口提供 CSS.highlights，可考虑用文本 Range 叠加高亮而不改写原始 HTML。能力检测不等于标注功能已验证。
- 既有术语表规定阅读记录关联具体文章版本；HTML 与 Markdown 属于同组不代表文本相同。

## 已确认范围

- 顶部默认紧凑工具条，隐藏 HTML 视图重复标题和文件名；可收起并保留恢复入口，记住选择。脚本禁用信息按需查看，实际问题用提示图标呈现。
- 同一阅读记录目录、记录格式和入口；HTML 与 Markdown 按真实源版本分别保存，在文章组层面汇总。
- 本轮包含文字高亮、引用和想法、创作灵感/待核查、整篇想法、可收起的标注侧栏、重新打开恢复高亮和记录回跳。
- 用户明确要求图片标注也在本轮实现，不延后。

## 新核实事实

现有 Markdown 图片标注针对整张 img 图片添加非空想法，不是图片内部框选或绘画。记录存储图片来源、替代文字和序号。HTML 预览会转换资源地址，因此需要独立保留原始来源，不能把预览中的长 data URL 直接写入记录。

## 第二轮确认（Q4–Q7）

- 图片采用整图笔记，不做局部框选、箭头或手绘。记录类型沿用想法、创作灵感、待核查；保存后显示图片标记并支持回跳。
- 标注时保存图片副本到阅读记录目录的附件区，按图片内容去重，并保留原始来源；HTML 内嵌图片同样存为附件，不将大段图片编码写进笔记。记录查看页需新增图片展示能力：现有 Markdown 图片记录仅显示说明与路径，不具备这个能力。
- 文字结合引用、前后文和位置定位；图片结合来源、内容特征与邻近文字定位。匹配不可靠时保留记录并标记“未定位”，不猜测第一次匹配或仅按序号定位。
- 选中文字后右键标注，图片右键记录；工具条提供整篇想法与标注面板入口。侧栏首次默认收起，随后记住选择。保存成功轻提示，不强制展开。

## 图片范围（Q8 已确认）

图片标注覆盖普通图片、本地 SVG 图片文件、内嵌 data 图片、picture/srcset 实际显示的图片，以及 HTML 内直接绘制的静态 SVG 图表；不将 CSS 背景或 canvas 作为本轮标注对象。

## 实施约束

- 本轮继续禁用网页自身脚本，标注交互由插件处理，不改写原始 HTML。
- 附件写入成功后再完成图片记录保存；写入失败要提示重试，不能显示成功但留下缺图记录。
- 重开与刷新先完成渲染再恢复定位；整篇想法没有段落定位要求，不应标为定位失败。
- 图片副本用于历史阅读记录，原页面图片替换后不得用新图冒充旧记录。
- 不在此次扩展中开启 HTML 音频或 PDF 导出；保持原有 Markdown/PDF 行为与日常安装版本功能。

## 已采用的技术方案

插件读取 iframe 内选区，保存摘录和上下文定位信息，复用阅读记录持久化；重新打开后在渲染层恢复高亮。原始 HTML 文件不写入标注。需要处理跨段落、重复文本、页面修改导致的定位失败，以及与现有记录查看和索引的兼容。

## 实施安排

1. 以日常安装的 0.4.6 加 HTML 增量为功能基线，核对与工作区差异，避免覆盖文章音频等已有功能。
2. 压缩 HTML 外框并实现顶部、侧栏状态记忆；保留展开入口及异常反馈。
3. 扩展 HTML 文字与图片的定位信息，兼容既有记录格式和解析器；复用保存、索引与分类流程。
4. 适配本地图片、内嵌图片、实际选中的自适应图片及静态 SVG 图表；保存内容去重的附件。SVG 副本需保留可见样式与必要本地资源，仍禁用脚本和自动网络加载。
5. 接入文字高亮、图片标记、侧栏、图片记录展示和记录回跳；可靠定位失败时保留记录为未定位。
6. 在隔离仓库完成验收，打包并交付结果。日常仓库部署沿用明确授权范围，并在实际替换前保留可恢复备份。

## 验收标准

- 顶部紧凑、收起与恢复均可用；长文件名、资源警告不重新撑出大块顶部空间。
- 选文跨文字节点/跨段落可保存；相同句子多次出现时不高亮错位。
- 刷新、关闭重开后能恢复高亮与图片标记；原文变化后可靠重定位，否则显示未定位。
- 普通图片、本地 SVG 文件、内嵌图片、自适应图片、内联静态 SVG 均可整图标注；保存的是当时所见图。
- 相同图片去重；原图删除或替换后仍能查看历史副本；图片写入失败不报告保存成功。
- 来源不同的 HTML/Markdown 记录分别保存，文章组汇总正确；文字/图片记录均可回到相应来源。
- 页面脚本继续禁用；资源边界和网络限制不被标注功能绕过。
- 现有 Markdown 批注、PDF 打开、文章音频及阅读记录查看无回归；运行既有测试、构建检查并在 Mac Obsidian 实际截图核对。
