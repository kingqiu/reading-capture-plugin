# 知见录侧栏收起与浅色主题

状态：完整方案已确认；代码及隔离仓库验证完成，日常仓库尚未部署。日期：2026-11-05。

## 已明确的用户需求

- 左侧筛选区域向左收起，右侧文章详情区域向右收起；两侧独立控制，初始均展开。
- 展开与收起沿用用户最近一次选择，直到用户再次调整。
- 中间文章卡片利用可用宽度，在合理空间下每行显示三张或四张。
- 新增浅色风格，右上角通过太阳/月亮图标切换。

## 第一轮已确认（Q1–Q5 按建议）

1. 列数按中间实际宽度自动调整，上限四列，窄窗口允许一至两列。
2. 收起后在各自边缘保留窄恢复入口；右侧收起时选卡片不自动展开，保留选中项；左侧收起不清空筛选。
3. 配色作用于插件首页、阅读器、阅读记录、创作灵感、创作项目及插件弹窗（按后续用户要求扩展）；初始沿用深色，切换后持久化；深色显示太阳（切到浅色），浅色显示月亮（切到深色）。
4. 展开状态和主题按当前设备、当前仓库记忆，避免多设备窗口尺寸不同而相互覆盖。
5. 浅色采用暖白背景、白色卡片与深灰文字，沿用现有蓝/橙/绿状态语义。

## 实施边界

用户确认后已完成实现；本轮不自动覆盖日常插件。正式实现需以日常 0.4.6 加 HTML 标注版本为基线，保护已安装功能。

## 已核实的布局事实

- 日常界面测得知见录可用宽度约 1408 CSS px，左筛选 230px、右详情 390px，中间约 752px，当前两列、每卡约 370px。
- 现有卡片按最小 260px 自动排列，无四列上限；新布局按知见录容器可用宽度计算，不能仅看整个应用窗口。
- 当前窄屏将左右区域上下堆叠；需要决定新的窄窗口展开行为。
- 现有选卡会重建页面，必须保留收起状态、筛选、选中项及合理的滚动位置。
- 日常仓库通过 Google Drive 同步；设备偏好需本地保存，不应直接写入随仓库同步的插件设置。
- 配色存在共享变量和知见录硬编码色值，主题变更须限定知见录范围。

## 第二轮已确认（Q6 按建议）

窄窗口无法容纳并排侧栏时，以左/右临时抽屉覆盖显示，最多同时打开一个；点击遮罩或 Escape 关闭。窗口尺寸变化不改写用户保存的展开偏好，回到足够宽度恢复此前状态。窄窗口首次仅保留两侧入口，避免遮挡正文；这个临时适配是“初始两侧展开”在空间不足时的例外。

## 最终范围与验收

- 宽窗口默认两侧展开，左右独立收起，边缘有恢复入口；不增加拖拽调宽和手动列数设置。
- 卡片按中间实际可用宽度自适应一至四列，避免横向溢出；展开与收起不清空筛选、选中项和搜索条件。右详情收起时选卡不强制展开。
- 窄窗口改为临时左右抽屉，最多同时打开一个，支持遮罩和 Escape 关闭；不改写宽窗口持久偏好。
- 知见录右上角太阳/月亮切换局部主题；初始深色，浅色使用暖白背景、白色卡片和深灰文字，保留状态色含义。
- 本设备、本仓库记住两侧展开状态和主题；重开、重启恢复，同设备同仓库多个知见录视图保持一致。
- 主题和布局切换不改变 Obsidian 全局主题、HTML 原文配色及阅读记录。
- 验证两种主题、四种左右展开组合、窄窗口抽屉、容器缩放、偏好恢复、筛选保留及已安装功能回归。
- 实现沿用日常 0.4.6 加 HTML 标注基线；本次设计确认不自动覆盖日常插件。
